# US-Presidents-Data-Cleaning-Project
## About This Project
This is my very first data cleaning project using **Microsoft Excel**! I worked on a dataset of US Presidents to practice making messy data clean, organized, and easy to read. I did this as part of my training in the **3MTT Fellowship**.

---

## The Files
* **`3MTT_Raw_Data_File.xlsx`**: This is the messy data I started with.
* **`DATA CLEANING PROJECT 3MTT.xlsx`**: This is the clean, final version after I fixed it.

---

## What I Did in Excel
Here are the steps I took to clean the spreadsheet:
1. **Looked for errors**: I went through the data to find missing information or wrong text.
2. **Cleaned up the text**: I used Excel tools to fix spaces, correct typos, and make sure names and words were capitalized properly.
3. **Fixed the formatting**: I made sure dates and numbers looked neat and consistent so the spreadsheet is easy for anyone to understand.
